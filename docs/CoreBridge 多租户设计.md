## 1\. 概述

### 1.1 背景

当前 Corebridge 管理后台为单租户模式，一套部署服务一个客户。需要改造为**单套部署、多租户隔离**的架构，使平台管理员能创建和管理多个企业客户（租户），每个租户拥有独立的数据空间和管理入口。

### 1.2 核心目标

- 平台管理员可创建、管理多个租户
- 租户间**完全数据隔离**（用户、资源、工作台、Agent 运行时数据）
- 租户有自己的管理员，自行管理租户内用户和资源
- 同一套管理后台，按身份区分菜单和视角
- 用户可属于多个租户，通过全局切换器切换

### 1.3 当前阶段范围

此次为**第一期**，范围如下：

| 维度 | 本期 |
| --- | --- |
| 租户模型 | 一个企业客户=一个租户 |
| 部署方式 | 单套多租户 |
| 资源策略 | 租户从零开始自建 |
| 配额限制 | 字段预留，不启用 |
| 角色矩阵 | 平台内置固定 |

**层级关系说明**：

| 角色 | 数据可见范围 | 操作权限 |
| --- | --- | --- |
| **平台管理员** | 全部租户的所有数据 | 管理租户生命周期 \+ 功能开关<br/>在具体租户视角下可查看和操作该租户资源 |
| **租户管理员** | 仅当前租户的数据 | 管理本租户用户、资源、工作台、分类、审批等 |
| **其他租户角色** | 仅当前租户的数据 | 按内置角色矩阵拥有不同权限 |

**数据可见性规则**：

> ⚠️**核心规则**：平台管理员可以看到所有租户下的所有数据（用户、资源、工作台等）；租户管理员和租户用户只能看到自己当前所在租户下的数据。

**资源归属**：所有资源（Agent/Skill/MCP/API/工作台/用户/分类）挂在租户下。**Agent 运行时归属**：会话、运行记录、产物、上下文均绑定租户，防止跨租户数据泄漏。

## 3\. 角色体系

### 3.1 角色划分

平台内置 7 个角色，分两级：

| 级别 | 角色 | 说明 |
| --- | --- | --- |
| 平台级 | 平台管理员 | 管理所有租户 \+ 功能开关 |
| 租户级 | 租户管理员（新增） | 管本租户用户 \+ 所有资源 |
| 租户级 | 业务管理员 | 按之前的权限不变 |
| 租户级 | 开发者 | 按之前的权限不变 |
| 租户级 | AI资产创建者 | 按之前的权限不变 |
| 租户级 | 标准用户 | 按之前的权限不变 |
| 租户级 | 受限用户 | 按之前的权限不变 |

### 3.2 管理后台权限管理修改点

1. 平台管理员支持所有租户的功能的查看和操作；
2. 租户管理员仅支持其所管理的租户内所有功能的查看和操作，不支持「租户管理」这个模块的任何操作。
3. 其他原本的内置角色权限划分不变。

## **5\. 功能需求**

### FR-1 租户管理

**功能描述**：平台管理员在后台创建和管理企业租户，每个租户拥有独立的数据空间。

**操作权限**：仅平台管理员可访问。

**功能点**：

| 编号 | 功能 | 描述 |
| --- | --- | --- |
| FR-1.1 | 新建租户 | 通过右侧抽屉表单填写以下信息并提交：<br/>**基础信息**：租户名称（必填）、租户标识（必填，仅允许小写字母开头、字母/数字/连字符）、企业简称（选填）、Logo 链接（选填）<br/>**联系信息**：联系人、联系电话、联系邮箱（均选填）<br/>**生命周期**：到期时间（选填，选择日期）、备注（选填）<br/>**初始管理员**（仅新建时显示）：管理员账号（必填）、管理员密码（必填） |
| FR-1.2 | 自动创建租户管理员 | 新建租户提交时，系统自动执行以下操作：<br/>① 创建一条租户记录（状态为"启用"，开通时间为当前时间，创建时间为当前时间）<br/>② 为该租户创建一条用户记录：登录账号=新建时填写的管理员账号，密码=新建时填写的管理员密码，角色="租户管理员"，所属租户=新建的租户，创建时间=当前时间<br/>③ 创建成功后提示"租户创建成功，管理员账号已生成"<br/>④ 该管理员账号立即生效，可直接登录管理后台，同时出现在权限管理的账号列表中 |
| FR-1.3 | 编辑租户 | 点击编辑按钮打开抽屉，回填已有信息。可修改名称、简称、联系人信息、到期时间、备注、功能开关。租户标识不可修改（禁用状态）。管理员账号字段不显示。保存后更新租户记录 |
| FR-1.4 | 启用/停用租户 | **停用**：点击"停用"按钮，弹出确认框"确认停用租户'\{租户名称\}'？停用后该租户下用户无法登录和使用。"，确认后状态置为"停用"。**启用**：点击"启用"按钮，弹出"启用租户"对话框，需选择新的到期时间，确认后状态置为"启用"并更新到期时间。**同时系统会在页面加载时自动检查：到期时间已过的租户，自动将其状态置为"停用"（无需手动操作）** |
| FR-1.5 | 删除租户 | 只有已停用的租户才能删除。启用状态的租户删除按钮为禁用（灰色不可点击），需先停用再删除；若强行调用删除逻辑，系统也会拦截并提示"请先停用该租户，再执行删除"。删除时弹出确认框"确认删除租户'\{租户名称\}'？该租户下所有资源将被清空，此操作不可恢复。"，确认后删除租户记录 |
| FR-1.6 | 功能配置 | 点击操作栏的功能按钮，弹出独立抽屉，以 checkbox 列出 8 个模块。保存后更新该租户的功能配置，生效后该租户菜单中不再显示关闭的模块入口<br/>**功能配置**（默认全选，可取消）：首页、集成平台-服务来源、集成平台-MCP 管理、集成平台-消费者管理、资源中心-Agent 管理、资源中心-Skill 管理、资源中心-MCP 管理、资源中心-卡片管理、资源中心-资源申请审批、效果调优-术语管理、效果调优-规则库管理、效果调优-业务实体管理、效果调优-评估管理、应用管理、系统管理-分类管理、系统管理-权限管理 |
| FR-1.7 | 搜索 | 表格上方搜索框，按租户名称进行模糊匹配过滤 |

### FR-2 分层导航（平台控制台 \+ 租户空间）-更新

**功能描述**：平台管理员的视角分为两个层级，参考 Microsoft 365 Admin Center 的多租户管理模式。全局视角（平台控制台）只管理租户；进入具体租户（租户空间）后才管理该租户的资源。

**操作权限**：平台管理员使用分层导航；租户用户始终在所属租户的租户空间内，无需分层。

**功能点**：

| 编号 | 功能 | 描述 |
| --- | --- | --- |
| FR-2.1 | 全局视角（平台控制台） | 平台管理员登录后默认进入全局视角，此时**没有租户上下文，不能切租户**。侧边栏只显示「租户管理」一项，用于查看和管理所有租户的列表（元信息：名称、标识、状态、到期时间、用户数等）。**右上角不显示租户切换器** |
| FR-2.2 | 进入租户 | 在租户管理列表中，每行租户的操作栏有「进入租户」按钮。**仅启用状态的租户可进入，停用租户的按钮为禁用（灰色不可点击）**。点击后切换到该租户上下文，跳转到该租户的首页，侧边栏展开完整功能菜单（集成平台、资源中心、效果调优、应用管理、系统管理等） |
| FR-2.3 | 租户空间 | 进入租户后，所有页面的数据均为该租户的数据。侧边栏不再显示「租户管理」（它是全局功能）。顶部栏右侧的切换器显示当前租户名称 |
| FR-2.4 | 返回全局 | 租户空间下，切换器下拉首项为「返回租户管理」。点击后清除租户上下文，回到全局视角的租户管理页，侧边栏重新只显示「租户管理」，右上角切换器隐藏 |
| FR-2.5 | 切换其他租户 | 租户空间下，切换器下拉列出**其他启用状态的租户**（停用租户不出现），选择后直接切换上下文（不回到全局），所有页面数据变为新租户的数据 |
| FR-2.6 | 租户用户视角 | 租户用户登录后直接进入所属租户的租户空间，无需经过全局视角。仅属于一个租户的用户不显示切换器；属于多个租户的用户通过切换器切换。**租户用户的切换器下拉仅列出所属租户，不显示「返回租户管理」选项**（该选项仅平台管理员可见） |

**交互形式**：顶部栏右侧切换器，格式`🏢 {租户名称} ▾`。切换器**仅在租户空间显示**，全局视角（租户管理页）不显示。下拉选项：租户空间下首项为「返回租户管理」\+ 各启用租户。

**数据规则**：`currentTenantId`为`null`表示全局视角（平台控制台），此时只渲染租户管理页面，不渲染任何租户级资源页面。进入租户后`currentTenantId`为该租户 id，所有资源页面按此过滤。这一机制天然保证：租户管理永远全局、资源永远租户隔离，不会出现"租户管理挂在某租户下"或"所有租户资源混在一起"的问题。

### FR-3 登录认证

**功能描述**：管理后台和工作台使用不同的登录流程。管理后台自动识别用户身份并跳转；工作台要求用户先选择所属租户再登录。

#### FR-3.1 管理后台登录

**操作权限**：所有用户。

| 编号 | 功能 | 描述 |
| --- | --- | --- |
| FR-3.1.1 | 登录流程 | 用户打开管理后台登录页，输入用户名和密码，点击登录。系统自动识别身份：先在平台管理员列表中匹配，命中则为平台管理员身份；未命中则在租户用户列表中匹配，命中则为租户用户身份；均未命中则提示"用户名或密码错误，请重试" |
| FR-3.1.2 | 平台管理员登录 | 认证通过后，系统记录登录状态（写入浏览器本地存储），进入全局视角（平台控制台），跳转到「租户管理」页。此时侧边栏只显示「租户管理」，右上角不显示租户切换器 |
| FR-3.1.3 | 租户用户登录 | 认证通过后，系统记录登录状态，自动识别该用户所属的租户。如果仅属于一个租户，默认选中该租户；如果属于多个租户，默认选中第一个租户。**直接进入该租户的租户空间（跳转到首页）**，数据仅展示当前租户的内容。登录后可通过顶部栏切换器切换到其他所属租户 |
| FR-3.1.4 | 输入校验 | 用户名或密码为空时提示"请输入用户名和密码" |
| FR-3.1.5 | 错误提示 | 登录失败时在表单内显示红色错误文字，仅清空密码框，保留用户名 |
| FR-3.1.6 | 登录态持久化 | 登录成功后将认证凭据和用户信息保存在浏览器本地存储中，刷新页面或重新打开浏览器可自动恢复登录态 |
| FR-3.1.7 | 退出登录 | 点击侧边栏底部的"退出登录"，清除本地存储的登录态，跳转回登录页 |

**数据规则**：平台管理员账号独立存储，租户用户账号按租户存储。同一个登录账号可以存在于不同租户下（视为不同用户记录），系统会识别出用户所属的全部租户。

#### FR-3.2 工作台登录

**操作权限**：所有租户用户（不含平台管理员）。

| 编号 | 功能 | 描述 |
| --- | --- | --- |
| FR-3.2.1 | 登录流程 | 用户打开工作台登录页，输入用户ID和用户名后，系统先查询该用户所属的租户列表。如果所属租户多于一个，登录页展示租户选择步骤，用户选择要登录的目标租户后完成登录；如果仅属于一个租户，也许展示租户信息 |
| FR-3.2.2 | 租户选择 | 当用户在多个租户中存在时，登录页显示"选择租户"步骤，列出该用户有权限的所有租户名称，用户需选择一个租户后才能继续。选中的租户即为本次登录的工作空间 |
| FR-3.2.3 | 登录后行为 | 登录成功后进入该租户的工作台，数据仅展示所选租户的内容（Agent 列表、对话记录等）。用户在工作台中无法切换租户 |

**交互形式**：与管理后台登录页为不同的页面入口。租户选择下拉形式展示用户所属的租户名称。

**数据规则**：工作台登录与管理后台登录共用同一套用户数据。同一个账号在不同租户下属于不同用户记录，登录时需明确指定目标租户。
